# Roadmap do TikSoda

## Feito

- [x] Conexão com a live, painel e feed de eventos
- [x] Ranking de likes e de coins da live, alertas
- [x] Prévia ao vivo de cada overlay no painel
- [x] Ações: presente → áudio/vídeo, meta de likes → áudio/vídeo, modo cortar e repetir
- [x] Meta de presente com link próprio por meta
- [x] Ranking mensal de coins e likes, com histórico
- [x] Temas por overlay (Escuro, Neon, Claro, Minimalista) com prévia
- [x] Metas de likes, seguidores, shares e coins em 5 modelos (presente, barra, círculo, número, copo)
- [x] Coroa no top 1 dos rankings
- [x] TTS com aba própria (comando, filtros, voz do Windows)
- [x] Roleta por comando no chat, por presente e pelo painel
- [x] Overlay de chat
- [x] Painel novo com menu lateral, avisos e animações
- [x] @ fixo, conexão automática e esperar a live começar
- [x] Overlay de contadores e último seguidor
- [x] Backup e restauração
- [x] App do Windows (TikSoda.exe) com ícone, atalhos e abrir com o Windows
- [x] Spotify: pedidos pelo chat com filtros (seguidor, fã-clube/Heart Me…), !pular por votação, overlay tocando agora

## Próximos

- [ ] **Comandos no chat** que tocam mídia (ex.: `!risada`) com limite de tempo
- [ ] **Sorteio de pessoas** (quem comentar uma palavra entra)
- [ ] **Boas-vindas** para quem entra na live

## Depois

- [ ] **Teclas do teclado**: ao receber um presente, apertar uma tecla no PC
- [ ] Integração com jogos
